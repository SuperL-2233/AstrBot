# CUGB 教务系统监控插件（astrbot_plugin_cugb_jwgl）

定时登录学校教务系统，监控课表、成绩、考试安排的变化并 QQ 私聊推送；
课表以 mportal 结构化数据为主构建按周课表，支持上课前提醒。

## 两个数据源

| 数据源 | 访问方式 | 认证 | 用途 |
| --- | --- | --- | --- |
| 教务处（jwgl，`/academic/`） | WebVPN（`portal_url`，elib.cugb.edu.cn 代理） | CAS 经 WebVPN 登录，会话 cookie 持久化 | 成绩、考试、课表快照（自由文本） |
| mportal（mportal.cugb.edu.cn） | 校园网/公网直连，无需 WebVPN | cas.cugb.edu.cn 的 CASTGC（独立会话） | 结构化周课表（主数据）、学期开学日期 |

两套 CAS 会话相互独立，各自都可能过期，登录流程会分别补齐（见下）。

## 登录流程

- `/教务登录` 发起：先验门户（WebVPN）会话；有效则继续探测 mportal。
- 哪一环落到 CAS 登录页，就在该页自动填账号密码并触发学校短信；用户把 6 位验证码发回来后用 `/教务验证码` 提交。
- 冷启动最坏情况需要两次验证码（门户一次、mportal 一次）；两次之后 cookie/CASTGC 都持久化在浏览器 Profile，之后不再需要。
- 每天早上按 `morning_login_cron` 检查登录态，失效时提醒用户重新登录。
- mportal 会话缺失时只降级对应功能，不影响教务处主流程，并节流提醒一次。

## 轮询行为（每 15±2 分钟，登录态有效时）

每轮依次执行：

1. **教务处快照**：成绩（当前+上一学期）、课表（当前+下一学期）、考试。
   - 首次运行回填：成绩/课表自 2020 春起全部学期。
   - diff 快照库：新成绩、新/变考试安排 → QQ 推送；课表变动只入库不推送。
2. **mportal 全周课表扫描**（`mportal_enabled` 时）：
   - 每轮扫描当前学期 + 下一学期的全部教学周。
   - 首次成功时回填 2020 春 → 下一学期所有学期（一次性，约几百个 API 请求）。
   - 每学期扫描结果做 SHA-256 哈希，**有变化才重建**该学期的按周课表；
     变化（或教务处文本变化）时对当前/下一学期做**交叉验证**，失配 QQ 推送。
   - 扫描失败仅降级日志，不影响本轮其他结果。

## 按周课表（主数据）

- 由 mportal 逐周结构化数据（课程、教师、地点、星期、节次、**每天日期**）构建，
  按学期分别存储（`weekly_timetable:<学期>`），当前学期另存默认键。
- mportal 不可用时降级为教务处自由文本解析（状态页可见，无日期信息）。
- 交叉验证：mportal 主课表 vs 教务处文本解析，按（星期+首节+课程名+地点）逐周比对，
  报告落库并在失配时推送；`/教务课表校验 [周次]` 可手动实时校验。

## 查询响应时间

- 课表、成绩、考试的 LLM 查询先读本地 SQLite 快照；缓存命中时不访问教务网站，
  不等待后台轮询占用的浏览器锁。空考试安排和已扫描的空学期也视为有效缓存。
- 本学期课表和最新成绩无需先调用状态工具确认学期。普通课表查询仅用已缓存的
  mportal 数据交叉校验，不会额外逐周扫描整个学期。
- `jwgl_get_week_courses` 的 `week` 支持 `today`、`tomorrow`、`current`、`next`，
  自动按插件时区和课表日期确定教学周；按天查询只返回当天课程，减少工具返回量。
  日期信息不足时明确提示指定周次，不让模型猜测开学日期。
- 后台仍按每 15±2 分钟更新缓存；需立即获取最新数据时使用 `/教务轮询` 或
  `jwgl_poll_now`。未缓存的数据仍可能需要实时查询或重新登录，指定的未缓存学期
  不会用其他学期的课程冒充。
- 插件更新后需重载，使缓存优先逻辑和新的工具说明生效；线上端到端耗时仍包含
  模型请求、网络和消息发送，本地缓存查询耗时不代表 QQ 的完整回复耗时。

## 上课提醒

- 每 60 秒检查一次当前学期按周课表，每门课开始前 `class_reminder_lead_minutes`
  （默认 15）分钟内向绑定 QQ 推送（课程、教师、时间、节次、地点），实际推送最多有一个检查间隔的延迟。
- 连堂课按一次上课安排提醒，例如第 3–4 节在第 3 节开始前提醒一次；当天有多门课时分别提醒。
- 已有部署需要将原配置的 `class_reminder_lead_minutes` 从 30 改为 15，并重载插件。
  在目标 QQ 会话发送 `/教务绑定` 后，课前提醒才会发往该 QQ；天气与教务的推送绑定独立。
- 教学周判定：优先用课表自带的 `week_dates` 精确日期映射；否则用开学日期推算，
  开学日期来源优先级：手动 `semester_start_date` > mportal 学期信息 > 不生效。
- 默认课表仍是旧学期时，根据 mportal 学期信息在已有缓存中查找包含当天日期的课表；
  无需重新登录即可使用已缓存的新学期课表，不修改教务系统返回的当前学期记录。
- 节次开始时间来自配置的 `section_start_times`（默认已按学校官方作息表填好）。
- 每条发送成功的提醒立即按日落库去重，重启不重复推送；失败的提醒在后续检查中重试，
  不阻塞其他课程，开始上课后不再补发；时间待定或节次时间无效的课自动跳过。
- `/教务状态` 显示提醒循环、日期来源和提前分钟数；登录失效不影响已经缓存的当前学期课表提醒。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/教务帮助` | 命令列表 |
| `/教务状态` | 登录态、轮询、数据源、校验结果、提醒状态 |
| `/教务登录` / `/教务验证码 <6位>` | 发起登录 / 提交短信验证码 |
| `/教务轮询` | 手动执行一轮检查 |
| `/教务成绩` | 最晚有成绩学期的成绩 |
| `/教务课表` | 当前学期课程列表（教务处快照） |
| `/教务周课表 [周次]` | 某一周（或各周总览）的按周课表 |
| `/教务课表校验 [周次]` | 实时拉 mportal 全学期并交叉验证 |
| `/教务考试` | 考试安排 |
| `/教务绑定` / `/教务解绑` | 绑定/解绑推送会话 |

## LLM 工具

- `jwgl_get_status`：运行状态（含周课表数据源、校验结果、开学日期来源）。
- `jwgl_get_scores`：按学期查成绩（缓存优先；不传学期时直接读取最新有成绩学期的缓存）。
- `jwgl_get_courses`：按学期查课表（缓存优先），不传学期时读取当前学期，记录含结构化
  `schedule`；已缓存 mportal 时附带本地计算的 `validation`，不为校验发起网络请求。
- `jwgl_get_week_courses`：按教学周或今天/明天/本周/下周查课表，读取持久化缓存；
  指定年份和学期且本地缺失时从 mportal 拉取该学期并缓存。
- `jwgl_get_exams`：考试安排（缓存优先）。
- `jwgl_request_login` / `jwgl_submit_sms_code` / `jwgl_poll_now`：登录与轮询编排。

## 关键配置项

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `portal_url` | 空 | 信息门户的 WebVPN 地址（必填） |
| `username` / `password` | 空 | CAS 学号/密码（仅用于自动提交登录第一步） |
| `poll_interval_minutes` / `poll_jitter_minutes` | 15 / 2 | 轮询间隔与抖动 |
| `mportal_enabled` | true | 关闭后周课表退化为教务文本解析 |
| `mportal_base_url` | `https://mportal.cugb.edu.cn` | mportal 地址 |
| `semester_start_date` | 空 | 开学日期手动覆盖项；留空自动取 mportal 学期信息 |
| `section_start_times` | 学校官方作息 | 节次号 → HH:MM |
| `class_reminder_enabled` / `class_reminder_lead_minutes` | true / 15 | 上课提醒开关与提前量 |
| `morning_login_enabled` / `morning_login_cron` | true / `0 9 * * *` | 早晨登录态检查 |
| `target_umo` / `owner_qq_id` | 空 | 推送会话覆盖 / 绑定权限 |

## 降级行为一览

| 场景 | 行为 |
| --- | --- |
| 门户登录态失效 | 轮询暂停并推送提醒；查询工具返回本地快照并注明 |
| mportal 未登录/扫描失败 | 当周课表用教务文本解析重建（如有变动）；交叉验证跳过；节流提醒补登录 |
| `mportal_enabled=false` | 周课表始终来自教务文本解析，无日期 |
| 课表日期与开学日期均未知 | 上课提醒不生效，状态页提示 |
| 教务处/mportal 数据不一致 | 主课表仍用 mportal；失配明细推送并写入状态 |

## 备注

- 夏季小学期无课时周课表为空属正常；term 代码映射 1=秋、2=春、3=夏，
  并用学期 startday 月份做一致性校验。
- 不持久化 mportal 原始响应中的教师工号等无关字段；数据库文件 0600 权限。
- 课表.html（mportal 周视图页面）与 `get-datatmp` 接口是同一份数据，插件只使用接口。
