# 百度天气助手（astrbot_plugin_baidu_weather）

基于百度地图开放平台 API 的 AstrBot 天气插件：按用户位置查询天气，并在每天早上按可自定义的时间推送当天天气预报。

## 功能

- **位置设定（常驻 + 行程双态）**
  - 说「我现在在[某地]」→ 设为常驻位置
  - 说「我未来 N 天都会在[某地]」或「我从 X 号到 Y 号在[某地]」→ 设为行程（限期内覆盖常驻位置，到期自动回退）
  - 地名通过百度地理编码解析为坐标后入库，后续查询/推送不再重复解析；解析失败时自动降级为区县名称直查
- **每日天气推送**：默认每天 07:50 推送当天天气预报（实时天气、昼夜预报、气象预警）。推送目标通过 `/天气推送绑定` 绑定当前会话，或配置 `push.target_umo`
- **推送时间自定义（常驻 + 限期双态）**
  - 说「以后每天 8 点推天气」→ 常驻推送时间
  - 说「接下来 3 天 6 点半推」→ 限期推送时间（到期自动回退）
- **天气查询**：直接问机器人即可查询当天或未来多天的天气（百度免费接口上限 7 天，超出自动截断）；跨行程的多日查询会按每天实际所在位置逐日拼接。LLM 工具默认返回实时天气、每日预报和预警，询问逐小时天气、降雨时刻或最高温时刻时使用 `hourly=true` 返回未来 24 小时明细。`/天气` 命令和每日推送继续附每 3 小时间隔的逐小时摘要。

## 命令

| 命令 | 说明 |
| --- | --- |
| `/天气帮助` | 显示帮助 |
| `/天气 [地点]` | 查询当天天气；带地点参数时查询该地点 |
| `/天气位置 [地点]` | 无参查看当前位置状态（常驻/行程）；带参数设为常驻位置 |
| `/天气推送时间 [HH:MM]` | 无参查看推送时间状态；带参数设为常驻推送时间 |
| `/天气推送绑定` | 将天气推送绑定到当前会话 |
| `/天气推送开关 [开/关]` | 查看或切换每日推送开关 |

## LLM 工具

- `get_weather(location, days, hourly=false)`：查询天气；`location` 留空时使用已保存的位置（行程优先）；按需用 `hourly=true` 请求逐小时明细
- `set_user_location(location, start_date, end_date)`：设置位置；不带日期为常驻位置，带起止日期（YYYY-MM-DD）为行程
- `set_weather_push_time(time, start_date, end_date)`：设置推送时间（HH:MM）；不带日期为常驻时间，带起止日期为限期时间

## 配置

| 配置项 | 默认 | 说明 |
| --- | --- | --- |
| `baidu.ak` | 空 | 百度地图开放平台服务端 AK（必填，未配置时插件返回明确的禁用提示） |
| `baidu.timeout_seconds` | 10 | 百度 API 请求超时时间 |
| `push.enabled` | true | 是否启用每日推送 |
| `push.default_time` | `07:50` | 默认推送时间，仅在用户从未设置过推送时间时生效 |
| `push.timezone` | `Asia/Shanghai` | 推送与日期计算时区 |
| `push.target_umo` | 空 | 推送目标会话，配置后优先于绑定命令保存的会话 |
| `permission.allowed_private_users` / `allowed_groups` | 空 | 私聊/群聊使用白名单，空为不限制 |

## 已知限制

1. 百度免费天气接口仅提供未来 7 天预报，更长的查询范围会被截断。
2. 若 AstrBot 在当天推送时刻之后才启动，当天的推送会被跳过，次日恢复正常。
3. `qq_official`（webhook/websocket）支持 C2C 私聊与群聊主动推送（受 QQ 官方频控约束）；频道（guild）场景依赖缓存的 msg_id，无法纯主动推送，请把推送绑定到私聊或群聊会话。
4. 位置与推送时间均为插件级单份状态（单一推送目标模型），任何被授权的用户都可以修改。
