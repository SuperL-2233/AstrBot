# astrbot_plugin_chaoxing_deadline

独立的超星学习通只读同步、任务查询、截止查询和 QQ 提醒插件。

## 能力

- 使用 `SuperL-2233/chaoxing-api` 提交 `554e01a` 已验证的只读登录和读取流程。
- 同步作业、视频/限时章节和讨论到插件独立的 SQLite 数据库。
- 按待办、已完成或全部状态查询作业、视频章节和讨论缓存记录。
- 查询未来若干天内有明确截止时间的待办任务。
- 将截止窗口内的任务去重推送到所有者绑定的 QQ 私聊。
- 单门课程局部失败不会阻断其他课程；全部课程主页失败时保留旧缓存。

普通视频和多数讨论可能没有独立截止时间。插件会显示“平台未提供明确截止时间”，且不会为这些条目编造或推送截止提醒。

“已完成”只依据学习通页面明确返回的完成、提交或批阅状态；“已截止/已结束”不会被误算为完成。讨论列表通常不返回当前用户是否参与过，因此已完成讨论只会包含来源明确标记为完成的记录，插件不会根据发布时间或截止时间猜测。

## 配置与使用

在 AstrBot 插件配置中设置 `enabled`、`phone` 和 `password`。插件不要求配置 QQ ID：查询命令可直接使用；提醒绑定和解绑必须在私聊执行，提醒目标就是最近执行绑定命令的私聊。手机号、密码、Cookie、动态课程令牌、SQLite 数据库和 QQ 会话目标都属于运行时私密数据，不应提交到 Git。

当前只保存一个提醒目标，因此新的私聊绑定会覆盖旧目标。若机器人对多人开放，请使用 AstrBot 平台或会话权限限制谁能执行插件命令。

启用后先在所有者 QQ 私聊中执行：

```text
/超星同步
/超星提醒绑定
```

查询命令：

```text
/超星任务 全部
/超星任务 作业
/超星任务 视频 课程关键词
/超星任务 讨论
/超星已完成 作业
/超星已完成 视频
/超星已完成 讨论
/超星全部 全部
/超星截止 7
/超星状态
```

本插件只读取数据，不提交作业、不发布讨论、不播放视频，也不写入学习进度。请遵守学校规定和超星平台条款，并控制同步频率。

Vendored 上游代码保留 MIT 许可证，位于 `providers/vendor/`。

## LLM tools

- `get_chaoxing_tasks`：按状态和类型查询作业、视频章节和讨论。
- `get_chaoxing_homeworks`：查询待办、已完成或全部作业。
- `get_chaoxing_video_chapters`：查询待办、已完成或全部视频章节。
- `get_chaoxing_discussions`：查询待办、已完成或全部讨论。
- `get_chaoxing_deadlines`：查询指定天数内的明确截止任务。

全局 `get_plugin_status` 由独立的 `astrbot_plugin_capability_registry` 提供，本插件只通过公开协议声明自己的能力和状态。
