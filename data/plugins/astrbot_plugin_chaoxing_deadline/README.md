# astrbot_plugin_chaoxing_deadline

独立的超星学习通只读同步、截止查询和 QQ 提醒插件。

## 能力

- 使用 `SuperL-2233/chaoxing-api` 提交 `554e01a` 已验证的只读登录和读取流程。
- 同步作业、视频/限时章节和讨论到插件独立的 SQLite 数据库。
- 查询全部待办或未来若干天内有明确截止时间的任务。
- 将截止窗口内的任务去重推送到所有者绑定的 QQ 私聊。
- 单门课程局部失败不会阻断其他课程；全部课程主页失败时保留旧缓存。

普通视频和多数讨论可能没有独立截止时间。插件会显示“平台未提供明确截止时间”，且不会为这些条目编造或推送截止提醒。

## 配置与使用

在 AstrBot 插件配置中设置 `enabled`、`phone`、`password` 和 `owner_qq_id`。手机号、密码、Cookie、动态课程令牌、SQLite 数据库和 QQ 会话目标都属于运行时私密数据，不应提交到 Git。

启用后先在所有者 QQ 私聊中执行：

```text
/超星同步
/超星提醒绑定
```

查询命令：

```text
/超星任务 全部
/超星任务 作业
/超星任务 视频 课程关键词
/超星任务 讨论
/超星截止 7
/超星状态
```

本插件只读取数据，不提交作业、不发布讨论、不播放视频，也不写入学习进度。请遵守学校规定和超星平台条款，并控制同步频率。
